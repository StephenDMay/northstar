# Bug Backlog

Broken behavior found while using the app. Add with `/bug-report`, or by hand using the format below. Fix with `/squash`, which turns a batch of bugs into a spec for `/imp`.

Not a bug: working-but-wrong code (tech debt → master.md Maintenance) or new behavior (feature → a roadmap step).

**Severity:** `blocker` (breaks a flow or embarrasses in a demo) · `annoying` (works around it) · `cosmetic` (looks off)
**Status:** `open` · `in spec` (picked up by `/squash`, being fixed)

Entry format:

```markdown
### B-001 — Short title
- **Found:** YYYY-MM-DD, where/how (e.g. demo prep, app testing)
- **Severity:** blocker | annoying | cosmetic
- **Area:** capability name, or blank if unsure
- **Status:** open
- **Repro:** steps to see it
- **Expected / Actual:** what should happen / what happens
```
